# 项目概述

本项目将实现一个短视频类 APP，核心功能主要包括：

1.  **推荐视频**：推荐视频列表，包括播放，点赞、收藏、评论等交互功能；
2.  **视频分类**：根据不同兴趣分类浏览视频内容，提供筛选和展示页面；
3.  **图片资讯**：可以查看站内的图集资源，进行点赞评论、收藏；
4.  **用户个人中心**：展示用户基本信息，支持查看历史记录、收藏及设置账户信息。

## 技术栈与架构设计

本项目将采用**Java**作为开发语言，并结合**MVVM架构**与**组件化开发**，以便于后期维护和扩展。以下是主要的技术点：

1.  **MVVM 架构**

    *   **ViewModel**：负责业务逻辑与数据处理，保持 UI 状态的独立性。
    *   **DataBinding**：将 XML 布局和 ViewModel 数据直接绑定，减少样板代码。
    *   **LiveData**：负责组件间的数据通信，保证数据的响应式更新。
2.  **组件化开发**

    *   将项目划分为多个功能模块：推荐模块、分类模块、搜索模块、用户模块等，实现解耦与独立开发。
3.  **核心技术选型**

    *   **Jectpack Media3**：实现高性能视频播放，支持短视频流加载与自定义播放体验。
    *   **Retrofit + OkHttp**：网络层框架，用于 API 请求和响应处理。
    *   **Room**：本地数据库，用于存储历史记录、收藏数据等。
    *   **Glide**：负责高效加载图片和缩略图，优化内存占用。
4.  **性能优化**

    *   对APP体积、内存、资源等方面进行性能优化；
    *   使用头条团队屏幕适配方案进行屏幕碎片化适配。

## 开发目标与学习价值

1.  **掌握 MVVM 模式开发短视频类应用**：结合 DataBinding 和 LiveData，打造清晰的架构，提升代码维护性。
2.  **理解安卓组件化开发思路**：通过模块化设计，提升代码解耦与复用能力。
3.  **深入视频播放与网络通信技术**：学习 商用开发中的整体开发流程，以及各个知识点之间的融会贯通，为后续开发奠定技术基础。
4.  **解决实际开发问题**：提升项目开发能力，成为独当一面的Android应用层工程师。



# 项目架构设计与搭建

在开发商用项目时，清晰合理的架构设计是必须要考虑的事情。我们将采用**MVVM 架构**结合**组件化开发**，实现高内聚、低耦合的模块化设计。

```
App模块 (壳模块)
├── Common模块 (公共模块)
│     ├── 网络层 (Retrofit)
│     ├── 数据库层 (Room)
│     ├── 工具类 (如日志、SP管理)
│     ├── 基础组件 (如BaseActivity、BaseFragment)
├── Feature模块 (按业务划分模块，比如推荐、个人中心等等)
│     ├── 首页模块
│     ├── 广场模块
│     ├── 发现模块
│     ├── 用户模块
├── Media3模块 (按功能划分模块，比如视频播放器)
│     ├── 视频播放逻辑 (Media3封装)
│     ├── 缓存逻辑

```

## **关键模块说明**

1.  **App 模块**

    *   作为壳模块，负责引入各个功能模块和公共模块。
2.  **Common 模块**

    *   公共模块，封装通用工具类与基础功能。
    *   包括网络请求、数据库管理、日志记录等。
3.  **Feature 模块**

    *   每个业务功能模块单独开发，独立职责、减少耦合。
    *   推荐、分类、搜索、用户模块实现功能闭环。
4.  **Media3 模块**

    *   独立处理视频播放逻辑，封装 Media3，为其他模块提供视频播放能力。
